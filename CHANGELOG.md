# Changelog

All notable changes to the AI Sales Automation Starter Kit are listed here. Versions follow semantic versioning (major.minor.patch).

## 1.0.0 (2026-10-20)

First release.

- `README.md`: who the kit is for, the start here order, what is inside, and a link to the video board.
- `01-THE-8-STEP-PATH.md`: the 8 steps, each with a goal, what to do this week, a checkable "done when" test, the real mistake to avoid from our own journey, and the prompt to use.
- `02-OUR-TOOL-STACK.md`: every tool we use today for calls, LinkedIn, WhatsApp, email, SMS, backend and frontend deployment, AI coding and models, CRM, DNS, team chat and UI, with official links, plus our voice tool journey with what we paid back then (clearly marked as past prices).
- `03-SYSTEM-MAP.md`: the step 8 campaign system as a diagram and a table, with the real tool at every box.
- `04-GLOSSARY.md` and `05-COMPLIANCE-BASICS.md`: plain word definitions, and what to check about consent, opt out, AI disclosure and calling hours (general information, not legal advice).
- `prompts/`: 9 detailed prompts, from learning the basics to a Claude Code build spec, post call analysis with a strict JSON schema, multi channel follow up, and a production test plan.
- `templates/`: a lead sheet template, a manual process log and a daily run check.
- `tests/check_kit.py`: checks links, long dashes, secrets, email addresses, private identifiers, required files and prompt code blocks. Runs on GitHub Actions for every change.
